1. 문제 추상화 핵심 개념

  1. 문제 : 우리가 생활 속에서 해결해야 하는 질문 또는 과제를 말한다.
  2. 초기 상태 : 문제를 시작할 때의 상황을 말한다.
  3. 목표 상태 : 목표에 도달한 상황을 말한다.
  4. 핵심 요소 : 문제 해결에 꼭 필요한 조건이나 요소를 말한다.
  5. 문제 추상화 : 문제 해결을 위해 문제에 대한 공통적인 특성이나 핵심 요소를 추출하는 것이다.

3. 알고리즘의 개념과 조건

  1. 알고리즘 : 문제 해결의 방법을 단계적인 절차로 표현한 것으로, 어떤 문제를 해결하기 위한 동작들의 모임이다.
  2. 입력 : 알고리즘을 시작하기 전에 필요한 정보나 데이터를 말한다.
  3. 출력 : 알고리즘이 수행되고 난 후 결과로 나타난 값을 말한다.
  4. 명확성 : 알고리즘의 각 단계에서 무엇을 하는지 명확하게 표현되어야 한다는 특징이다.
  5. 수행 가능성 : 알고리즘의 각 명령이 논리적으로 수행 가능해야 한다는 특징이다.
  6. 유한성 : 알고리즘의 명령은 주어진 절차와 횟수만큼 처리한 후 반드시 종료되어야 한다는 특징이다.
💡 효율적인 알고리즘의 조건:
효율적인 알고리즘은 작업량이 적어 수행 시간이 짧고, 기억 장소의 사용량이 적은 알고리즘을 말한다.

5. 문제 해결 전략 알아보기

  • 전체 탐색 : 모든 가능성을 적용하여 처음부터 끝까지 데이터를 탐색하여 찾는 방법이다.
  • 분할 정복 : 크고 복잡한 문제를 해결 가능한 작은 문제로 나누어 해결한 후 합치는 방법이다.
  • 규칙 찾기 : 문제에서 규칙성이나 패턴을 찾아서 해결하는 방법이다.
  • 되추적 : 문제의 해답을 찾아가다가 잘못된 것 같으면 되돌아가서 다른 선택을 하는 방법이다.

6. 프로그래밍 언어의 종류와 특징

종류 의미 및 예시
프로그래밍 언어 프로그램을 작성할 때 사용하는 언어로 종류가 다양하다.
블록 기반 프로그래밍 언어 블록형태로 구성된 명령어를 마우스로 끌어와 조립하는 방식으로 프로그램을 작성한다.
ex) 엔트리, 스크래치, 앱인벤터 등
텍스트 기반 프로그래밍 언어 키보드로 명령어를 일일이 입력하여 프로그램을 작성한다.
ex) C언어, 파이썬, 자바 등

7. 데이터의 순차 저장 핵심 개념과 용어

  1. 변수 : 프로그램 실행 중 발생하는 하나의 데이터 값을 저장하기 위한 기억 장소이다.
  2. 리스트 : 여러 개의 데이터를 순차적으로 저장하고 하나의 이름으로 관리할 수 있는 자료 구조이다.
💡 리스트의 특징:
① 리스트에 입력된 데이터를 ( 항목 )이라고 하며, 각 항목은 ( 순차적 )으로 저장된다.
② 리스트는 서로 다른 ( 유형 )의 데이터를 저장할 수 있다.
③ 각 항목에는 ( 번호 )가 부여되며, 번호는 ( 1 )번부터 시작된다.
④ ( 항목 번호 )를 활용하면 데이터의 검색 및 수정, 삭제를 쉽게 할 수 있다.

8. 논리연산자와 중첩제어문 핵심 개념과 용어

  1. 논리연산자 : 연산자 간의 논리적인 관계를 나타낼 때 사용하는 연산자로, 연산 결과는 참 또는 거짓이다.
  2. 논리곱(AND) : 두 연산이 모두 참인 경우에만 결과가 참이고, 나머지는 거짓인 연산이다.
  3. 논리합(OR) : 두 연산 중 하나라도 참이면 결과가 참이고, 둘 다 거짓일 때만 거짓인 연산이다.
  4. 논리부정(NOT) : 연산이 참이면 거짓으로, 거짓이면 참으로 바꾸는 연산이다.
  5. 중첩제어문 : 제어문 안에 또 다른 제어문이 포함되어 있는 프로그램 구조이다.

9. 함수와 디버깅 핵심 개념과 용어

  1. 함수 : 프로그램에서 특정 기능을 수행하기 위해 여러 개의 명령어를 작은 단위의 블록으로 묶어 놓은 것이다.
  2. 호출 : 만들어진 함수가 프로그램 안에서 실행되도록 불러오는 과정이다.
  3. 디버깅 : 프로그램 실행 중 발생한 오류가 있는 코드를 찾아내고 수정하는 과정이다.
💡 함수를 사용하면 좋은 점 (교과서 128쪽):
① 프로그램에서 같은 작업을 여러번 반복하여 사용하는 부분을 함수로 만들고, 이 함수를 호출하여 이용하면 시간과 노력을 줄일 수 있다.
② 반복되는 부분도 함수만 수정하여 재사용할 수 있으므로 프로그램을 쉽게 수정할 수 있다.

Part 2. 인공지능과 데이터

11. 인공지능과 데이터 핵심 개념과 용어

  1. 인공지능(AI) : 인간의 지적 능력을 모방하여 소프트웨어로 만드는 것이다.
  2. 인공지능 모델 : 데이터를 학습하여 만들어진 모델로, 이 모델을 이용하여 분류, 예측 등의 작업을 수행한다.
  3. 인공지능 시스템 : 인공지능 소프트웨어를 사용하여 사용자의 요구나 사용 목적 등을 달성해 주는 컴퓨팅 시스템이다.
  4. 학습 데이터 : 인공지능의 학습을 위해 입력하는 데이터이다.
  5. 지능형 에이전트 : 역동적인 외부 환경을 인지하여 지능적으로 판단하고 의사 결정을 하며, 자율적으로 행동하여 목적을 이루도록 하는 시스템이다.

1) 인공지능의 3대 핵심 특성

  1. 수치 데이터에서 비어 있는 수치를 ( 결측 )치, 정상 범위를 벗어난 수치를 ( 이상 )치라고 한다.
  2. 불필요하거나 중복된 데이터를 제외하는 등 학습 데이터로 사용하기 위해 정제하는 작업을 ( 데이터 전처리 ) 작업이라고 한다.
3) 신선한 과일 및 상한 과일 데이터 수집 시 유의점 4가지:
① 과일이 사진 속에 뚜렷하게 드러나는 사진을 모은다.
② '신선함', '상함'을 올바르게 붙여서 분류(라벨링)한다.
③ 신선한 과일과 상한 과일의 이미지 수를 비슷하게 충분히 모은다.
④ 개인정보가 담긴 사진은 제외한다.
